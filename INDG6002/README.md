## Layout

Each numbered folder is one top-level item from the Ultra course outline
(modules, orientation, assessments, readings...).

```
02 - Unit orientation/
  material/*.epub        Blackboard Ally ePub for each document
  html/*.html            same document as HTML (keeps video/link markup the ePub drops)
  files/                 original attachments (mostly the weekly readings, PDF/DOCX)
  extracted_content.txt  text extracted from the ePubs (same method as extract_all.py)
  structure.md           item tree for this section
  videos.md              videos in this section, with summaries
```

Also:

- `documents.json` — every document, its section and breadcrumb path
- `VIDEOS.md` — video index for the course
- `../videos/` — Panopto delivery metadata, YouTube metadata, caption transcripts
- `../video_jobs.json`, `../resolved.json` — scrape provenance
