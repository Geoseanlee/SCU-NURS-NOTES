# PHAR2001 — Module 3: The endocrine system / 内分泌系统

## 先画反馈轴

标出腺体、激素、靶组织与反馈信号；区分分泌不足、分泌过多和组织反应异常，理解替代治疗与抑制治疗为何目标不同。

## 垂体相关激素

课程介绍 oxytocin，并复习 ADH/vasopressin 与 growth hormone。后两类课文标为 non-compulsory，仍完整保留，不能因为存在档案就认定都是必考。

## 甲状腺轴

把甲状腺激素与代谢活动联系起来，比较甲减与甲亢，以及补充激素和降低激素作用的不同目标。甲亢章节在原文中标为选学。

## 糖尿病的学习位置

原文说明糖尿病主要通过 tutorial 与 case study 展开，而不是普通独立视频章。复习时必须同时查看 tutorial 材料，目录下没有子视频不等于整个课程没有该主题。

## 肾上腺与糖皮质激素

以应激轴和糖皮质激素生理作用理解治疗效果与长期暴露风险。反馈抑制和疗程很重要；不能根据本摘要自行调整或停用激素。

## 骨健康

从骨吸收与骨形成理解骨质疏松及内分泌调节，比较 bisphosphonates、teriparatide 与 SERMs 的目标，而不是把它们当作同一种补充剂。
