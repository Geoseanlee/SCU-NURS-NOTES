# PHAR2001 模块一：以胃肠系统理解药物

## Overview

模块一（Module 1）用胃肠系统（gastrointestinal tract, GIT）的常用药来搭建药理学的底层框架。第一章先从最简单的一类药入手：抗酸药（antacids）与泻药（laxatives）。它们大多不被吸收，靠直接的化学反应或物理作用起效，因此可以把“药物如何起效”这件事拆成最清楚的样子。后续章节沿用同一套临床思路，依次引入细胞受体（cellular receptors）与药效动力学（pharmacodynamics）、吸收—分布—代谢—排泄（absorption, distribution, metabolism, excretion, ADME）与药代动力学（pharmacokinetics）、酶抑制（enzymatic inhibition），最后是神经传递（neurotransmission）与止吐药（antiemetics）。[S1][S2]

这个模块明显比其他模块大：约四小时的视频课，加上配套活动，因为后面每个模块都默认你已经掌握这些概念。期末测验的题目来自视频和活动，所以那些动画讲解不是装饰，而是必读内容。[S1][S3]

## What you should be able to do

学完本模块后，你应当能够：

- 解释为什么 antacids、laxatives 与 mineral oil 可以在不被吸收的情况下起效，并把这一特点与它们的安全性问题联系起来。[S2][V25]
- 从作用机制、是否吸收、电解质负荷、对排便的影响和 rebound（反跳）程度五个方面比较四类 antacids。[S5][V44]
- 运用 Rome criteria 判断便秘是否成立，并识别使 laxatives 变得危险的 red flags。[V28]
- 区分 osmotic、stimulant、mineral oil 与 detergent（faecal softener）四类 laxatives 的作用机制、起效时间、适应证与危害。[V33][V24][V40]
- 说明四类 cellular receptors，并解释 affinity、potency、selectivity、agonism、antagonism 与 inverse agonism。[V6][V18][V30]
- 解释 ADME 的每个环节、first-pass metabolism、protein binding、half-life，以及 first-order 与 zero-order elimination 的差别。[V36][V34][V35][V7]
- 说明 reversible 与 irreversible enzyme inhibitors 的工作方式，以 proton pump 为模型，并预测 drug interactions。[V11][V31][V43]
- 把四条 emetic pathways 与各自的 neurotransmitters 对应起来，并为 motion sickness、chemotherapy 或 GIT irritation 选择合适的 antiemetic。[V12][V10][V2]

## 1. 把胃肠系统当作教学实验室

消化系统适合作为药理学的第一站，因为它的药物刚好把三个容易混淆的层次分开：直接化学作用、受体作用与酶作用。Antacids 通过中和胃酸起效；laxatives 改变肠内容物的物理状态；loperamide 作用于受体；omeprazole 抑制酶。把这四幅图景建立起来，之后遇到任何系统的药物，都可以用同一组问题去拆解。[S2][V25][V16]

课程的顺序是固定的。第一章用 antacids 与 laxatives 讲直接作用和化学作用；第二章用 loperamide 与 opioids 讲 cellular receptors 和 pharmacodynamics；第三章用 histamine 2 blockers 引入 pharmacokinetics，再借 omeprazole 复习 ADME；第四章通过 proton pump inhibitors 讲 enzymes 与 enzymatic inhibition；第五章讲 neurotransmission 与 antiemetics。[S1][V8][V26][V22]

| 章节 | 主要药物例子 | 概念重点 |
|---|---|---|
| 1 | Antacids、laxatives、mineral oil、docusate | 直接作用与化学作用；先评估安全性 |
| 2 | Loperamide、其他 opioids | Cellular receptors；pharmacodynamics |
| 3 | Histamine 2 blockers；以 omeprazole 复习 | Absorption、distribution、metabolism、excretion |
| 4 | Omeprazole 及其他 proton pump inhibitors | Enzymes；reversible 与 irreversible inhibition |
| 5 | Antihistamines、anticholinergics、5-HT3 与 dopamine-2 antagonists | Neurotransmission；emesis pathways |

这张表概括了模块概览与各章导言所描述的结构。[S1][S12][S21][S30][S37]

贯穿全模块的方法比任何单个药物都重要。面对一种药，先弄清它要治疗的疾病以及该疾病本身的安全问题；再复习器官的正常解剖与生理；然后理解病理生理（pathophysiology），也就是功能失常的生理；最后才把药物放回这幅图里。这样就不会把 indications 与 contraindications 背成两张互不相关的清单。[S7][V15][V28][V32]

安全必须排在最前面，因为就诊时的主诉可能比患者想消除的症状更危险。严重便秘可能提示 intestinal obstruction；此时给 laxative 会增加梗阻前方的蠕动和液体，进而导致肠破裂、peritonitis、住院甚至死亡。Diarrhoea 可以让婴儿比成人更快脱水；vomiting 反复发生则可能造成 metabolic alkalosis。只压住症状而掩盖病因，可能延误真正致命的处理。[V5][V27][V19]

解剖图景要简单但清晰。GIT 有外层纵行肌与内层环行肌，两层都由 enteric nervous system 控制；这是分布在肠壁内的大型局部神经网络。小肠与大肠全程都有腺体向 lumen 分泌黏液等物质。肌肉的舒张与收缩协调推进内容物。当肠道感受到阻塞或细菌毒素时，阻塞前方的肌肉会更强力地收缩，黏液分泌也增加，这解释了梗阻为什么会出现绞痛和“黏液样腹泻”。[V28]

胃黏膜形成 gastric pits，其中有 parietal cells。Parietal cell 通过 hydrogen–potassium ATPase pump 把 hydrogen ions（protons）送入胃腔，氢离子再与 chloride 结合成 hydrochloric acid。Histamine 2 blockers 与 proton pump inhibitors 都作用于这个细胞，所以这两类药适合放在一起理解。[V25][V13][V31]

胃酸不是废物。它开始分解食物，帮助吸收部分营养素和许多药物，并抑制随食物进入的微生物以及胃内细菌的增殖。胃酸被长期抑制后，这些功能缺失就会变成副作用：营养吸收下降、感染风险上升、部分药物吸收改变。[V29]

模块还教“怎么学”。学习分层次：记住事实、理解概念、把概念应用到情境。每节课后的 quiz 不是障碍，而是强制提取与应用；正是这个过程让记忆更牢固，也训练 clinical reasoning。[V1]

## 2. 抗酸药（Antacids）

Antacid 是一种碱，作用对象是胃里已经存在的酸。它不减少胃酸分泌。Magnesium 与 aluminium 盐吸收很少，作用局部而短暂；sodium 与 calcium 盐可被吸收，因此会带来全身效应。被认可的适应证是偶发 heartburn；重要的禁忌证是慢性 heartburn，因为持续反流已不再是单纯的 heartburn，而是 gastro-oesophageal reflux disease（GORD，也写作 GERD）。[S3][V25][V44]

这个区分很关键。Heartburn 是胃酸从胃反流到 oesophagus 的日常说法。反流长期存在时称为 GORD；到了这个阶段，事后中和胃酸并不能保护食管黏膜。胃酸反复溅到食管细胞，可引起 dysplasia（癌前改变），dysplasia 再进展就可能成为 oesophageal cancer。患者自行用药十年、二十年甚至三十年，可能一直没做过评估；多数医生建议反流约二十年后做 endoscopic evaluation。[V25][V38]

反流的发生有两种基本情形：食管下端的屏障失效，或胃内容物被向上推。Lower oesophageal sphincter 是一圈肌肉，平时保持一定张力，像闸门一样防止胃酸上涌。降低其张力的因素包括 alcohol、muscle relaxants、cigarette smoke 与 opioids。胃过满（如暴食）或 central obesity（脂肪集中在腹部）会把内容物推向胃的上部。Hiatal hernia 是胃的上部穿过 diaphragm，属于最不可逆的易感因素，约影响五分之一的人。[V25]

中和反应的化学很直接。以 magnesium hydroxide 为例：分子在胃内解离，magnesium 与 hydrochloric acid 中的 chloride 结合，两个 hydroxide 基团与 hydrogen 结合生成两分子水。产物是水和 magnesium chloride。整个过程不涉及 receptor，也不涉及 enzyme。[V44]

澳洲常用的 antacids 有四类，差别主要在于反应之后发生什么。[S5][V44]

| Antacid 类型 | 体内去向 | 主要排便影响 | 其他问题 |
|---|---|---|---|
| Magnesium hydroxide 或 magnesium citrate | 吸收很少；生成具有渗透活性的 magnesium chloride | 把水拉入肠腔，引起 diarrhoea | 腹泻是主要缺点 |
| Aluminium hydroxide | 吸收很少；生成 aluminium chloride | 引起 constipation | 与部分药物和营养素结合，降低吸收 |
| Sodium bicarbonate | 可被吸收 | — | Sodium（盐）负荷高；可产生全身效应 |
| Calcium carbonate | 可被吸收 | — | Rebound hyperacidity 最明显 |

Sodium bicarbonate 与 calcium carbonate 会被吸收，所以全身副作用更多。Sodium bicarbonate 增加盐负荷；calcium carbonate 引起的 rebound 最强。因此这两类通常不是首选。Magnesium 与 aluminium 盐的全身作用最少，但它们相反的排便作用正好成为个体化选择的依据。[V44]

选择逻辑很朴素。平时容易便秘的来访者通常更能耐受 magnesium antacid，因为渗透活性的 magnesium chloride 会软化粪便；本来就大便偏稀的人则更适合 aluminium antacid，因为它倾向引起便秘。开药者不是只处理 heartburn，而是在把盐的种类与患者的排便型态配对。[S5][V44]

第二个安全问题是 rebound。Antacid 降低胃内酸度后，胃会感知到“酸不够”，并发出增加胃酸分泌的信号，结果可能比用药前更酸，称为 rebound hyperacidity。这是 homeostasis 的具体例子：身体会守住内环境的设定点，药物打破设定点，身体就启动代偿。同样的逻辑可以解释为什么某些 diuretics 一开始能降血压，过一段时间却因身体调整而失效。[V38]

Rebound 也解释了为什么在可以避免的情况下，antacids 要与其他药或进餐错开。胃酸是部分药物与营养素吸收所需，aluminium 盐还会直接结合某些药物。把 antacid 放在餐前或餐后一至两小时、与其他药物相隔一至两小时，可以同时减少 pH 影响与结合作用。[V38][V44]

Antacids 是非处方药，但“非处方”不等于“无风险”。风险包括：用来自我治疗而延误评估、rebound、电解质与排便影响、与药物结合，以及少见但严重的后果——未处理的反流可进展为 dysplasia，甚至 oesophageal cancer。[S4][V38][V44]

## 3. 便秘与泻药（Laxatives）

Laxatives 是最常被滥用的药物，因为很多人并不清楚 constipation 的定义。Rome criteria 要求在过去任何十二周内，符合以下五项中的至少两项：每周排便少于三次；超过四分之一的排便为硬便；超过四分之一有排不尽感；超过四分之一需要过度用力；需要 digital manipulation 帮助排出。没有达到两项，就只是“感觉便秘”，而不是诊断意义上的 constipation。[V28]

即使确诊便秘，laxative 也不是一线处理。最先建议的是增加饮水、增加富含纤维的食物，或加入 psyllium，然后再判断是否仍需 laxative。多数国家的指南都把顺序写得很清楚。[V15]

理解这个顺序需要 motility 的图景。环行肌与纵行肌在 enteric nervous system 控制下推进内容物，而 enteric nervous system 又受 autonomic nervous system 影响。Sympathetic 的“fight or flight”分支会关闭消化，把血液与注意力留给肌肉；parasympathetic 的“rest and digest”分支则增加肠道蠕动与分泌。因此，模拟 sympathetic 作用的药，或阻断 parasympathetic 作用的药，都会造成 constipation。Opioids 是最典型的例子，它们直接作用于 enteric nervous system 而减慢蠕动。[V28]

其他原因也来自同一套生理。有人天生 motility 较低或黏液分泌较少；膳食纤维不足，内容物无法被撑开和松散；饮水不足，粪便变硬；即使水分充足，长期压抑排便冲动也会让结肠回收更多水分，使粪便更干。Constipation 还可能是 hypothyroidism 或其他全身性疾病的首发症状，因此持续便秘值得评估，而不是再买一盒泻药。[V28]

给 laxative 之前必须识别 obstruction 的 red flags。梗阻会造成 colicky pain（一阵一阵的绞痛）、少量黏液样腹泻（只有黏液能越过阻塞处）以及腹部膨隆。并非每个患者三项俱全，但出现任何一项都要改变处理方案。梗阻时使用 laxative，会增加阻塞前方的蠕动与液体，可能导致肠破裂、peritonitis、住院和死亡。因此 laxatives 在 intestinal obstruction 中是 contraindicated。[V28][V5][V33]

### 渗透性泻药（Osmotic laxatives）

Osmotic laxatives 把水拉进肠腔。Cell membrane 是 semi-permeable：水可以自由通过，具有渗透活性的颗粒不能。水于是向颗粒浓度高的一侧移动。当 magnesium citrate、magnesium hydroxide 或 lactulose 存在于肠腔时，水跟着药物进入肠道，内容物变软，便秘缓解。[V33][S8]

Magnesium 盐在本模块里有双重身份。作为 antacid，它中和胃酸并生成 magnesium chloride；作为 laxative，同样的 magnesium chloride 具有渗透活性，把水拉进肠道。这解释了为什么 magnesium antacid 会引起腹泻，也解释了 milk of magnesia 为什么能当泻药。[V33][V44]

Osmotic laxatives 在 obstruction 中是 contraindicated，理由同上：液体在阻塞前方积聚，可能把肠管撑破。大剂量使用而饮水不足还会造成脱水；由于效应与剂量成比例，这个风险更值得注意。[V33]

这种比例关系叫 linear dose response。以剂量对效应作图，曲线持续上升：药越多，效应越强。这在药物中并不常见。多数药物在略高于推荐剂量时就达到最大效应，再增加只增加毒性而不增加疗效。Paracetamol 是课程里的标准反例：略高于常规剂量即可达到最大镇痛效果，再往上只会增加 liver toxicity，不会更止痛。因此，把每种药都当成 osmotic laxative 那样“多吃一点更有效”是危险的。[V33]

Lactulose 是一种吸收很差的糖，非常甜，并非人人都能耐受，所以有些人会与开水、果汁或牛奶同服。Magnesium citrate 与 magnesium hydroxide 是另外两种常用药。[V33]

### 刺激性泻药（Stimulant laxatives）

Stimulant laxatives 通过刺激肠道起效。刺激增加蠕动与分泌，转运加快又减少液体回收时间，粪便因此更湿、更容易排出。该组包括 bisacodyl、sodium picosulfate、senna 与 castor oil。[V24]

它们强而有效，所以使用范围很窄。可接受的用途是：其他方法都无效时的偶发便秘，以及 colonoscopy 或其他操作前的肠道准备。不能长期规律使用。[V24]

副作用正来自这种强度。第一是 rebound constipation：平滑肌适应了强刺激，之后需要同样强度的刺激才能运动，停药后自身 motility 明显下降。第二是长期使用损伤结肠，使其永久性地更难推动粪便。第三是严重的 electrolyte abnormalities。包装上写“温和”并不能改变这些风险。[V24]

Sodium picosulfate 是 prodrug，必须代谢成活性形式。它不被吸收，肝脏无法激活它，真正完成转化的是 intestinal bacteria。因此 sodium picosulfate 只有口服才有效，因为只有口服才能让它与结肠细菌长时间接触。它常与 osmotic laxative 合用，作为 colonoscopy 或影像检查前的肠道清洁方案。[V24]

Bisacodyl 还有额外副作用：mild proctitis，即直肠内层炎症并伴 rectal mucosa 脱落。[V24]

起效时间取决于给药途径。口服 stimulant laxatives 通常六至十五小时起效，suppository 约十五至六十分钟，enema 约五至十五分钟。口服制剂通常做成 enteric coated，使药物经过胃时不溶解；enteric-coated 药片必须整片吞服，不能咀嚼。[V24][S9]

### 矿物油与粪便软化剂

Mineral oil 是药用矿物油，人体既没有吸收机制，也没有排泄机制。听起来无害，但意味着一旦进入循环就出不去。它只能间歇使用，不能长期依赖。它还会溶解脂溶性维生素，干扰 vitamin A、vitamin D、vitamin E 与 vitamin K 的吸收，因此应空腹服用。[V40][S10]

Faecal softeners 又称 emollients 或 surfactants，docusate 是代表。它们具有 detergent-like properties，能让水与脂肪在粪便中混合，从而水合并软化粪便。同样的去污作用会增加脂溶性药物的吸收，可能提高其毒性。[V40]

最危险的是 mineral oil 与 detergent softener 合用。Detergent 把油乳化成更小的油滴，并作用于肠壁细胞的 phospholipid bilayer，使部分 mineral oil 被吸收。由于没有排泄途径，免疫系统把这些油滴视为异物，用 B cells、T cells、neutrophils、macrophages，最后是 fibroblasts 将其包裹，形成 granuloma。结果是一个坚硬结节，若不手术切除会终生存在。因此这两类药属于 strictly contraindicated。[V40]

“Contraindicated”与“strictly contraindicated”程度不同。许多药物只是“一般情况下避免合用，特定情形仍可用”；strictly contraindicated 则是永远不能一起用。这两个词也不只用于药物配对：某种药可以在 pregnancy、congestive heart failure，或手术前七天内被列为 contraindicated。[V40]

| Laxative 类别 | 代表药 | 机制 | 主要风险 |
|---|---|---|---|
| Osmotic | Magnesium citrate、magnesium hydroxide、lactulose | 把水拉入肠腔 | 脱水；obstruction 时禁用；linear dose response |
| Stimulant | Bisacodyl、sodium picosulfate、senna、castor oil | 刺激肠道，增加蠕动与分泌 | Rebound constipation；结肠损伤；电解质丢失 |
| Mineral oil | 药用 mineral oil | 不被吸收 | 脂溶性维生素吸收不良；无排泄途径 |
| Faecal softener | Docusate | Detergent 使水与脂肪混合 | 增加脂溶性药物吸收与毒性 |

这张表压缩了四类药物的差异，具体机制见上文。[V33][V24][V40]

## 4. 腹泻：先评估安全，再考虑止泻

Diarrhoea 是下一章的前置问题，因为 loperamide 用于治疗它。主要安全问题是脱水、电解质紊乱与酸碱失衡。正常情况下，肾脏调节液体、电解质与 pH；腹泻时肠道绕过了这套控制。患者随粪便丢失 potassium 与 magnesium，并排出 bicarbonate——维持血液不过酸的碱性分子。严重紊乱可引起 convulsions、其他神经系统症状、coma，甚至死亡。[V27][S13]

易感人群分布并不均匀。婴儿与高龄者脱水最快；婴儿对较小的电解质波动也更敏感，可能出现脑损伤或死亡。Obesity 是独立危险因素：adipose tissue 的含水量只有约百分之十，而其他组织平均约百分之七十，所以同样体重下，肥胖者的水分储备更少。[V27]

体征包括口干、尿色深而浓缩、明显口渴，以及 skin turgor 下降。Skin turgor 的检查是捏起手背皮肤，看它回弹多快；脱水时回弹变慢。高龄者基础回弹本来就差，因此要结合基线判断。[V27]

首要处理是补液：足量饮水与 oral rehydration solution。减少腹泻的药物要在患者脱离脱水危险之后再考虑。这与便秘的处理遵循同一条“安全优先”逻辑，也是模块先用一整节课讲疾病、再讲药物的原因。[V27]

## 5. 药物命名与药物类别

一种药至少有三类名字。Chemical name 描述分子结构，只有实验室合成人员使用；brand name 是厂商的商品名；generic name 是化学名的缩写，也是发药标签上出现的名字。同一个分子可以有上百个 brand names，所以最值得先记的是 generic name。[V20][S14]

Generic name 常带一个提示药物类别的 affix。以 -olol 结尾的是 beta blockers，会减慢心率、降低血压；以 -azepam 或 -azolam 结尾的是 benzodiazepines，用于焦虑与癫痫。Corticosteroids 不那么整齐：-asone、pred- 与 -cort 可能出现在词尾、词首或词中。[V20]

Drug class 指化学结构相似、作用机制相似，或两者兼有的药物群体。Antacids 中和胃酸；histamine 2 blockers 也降低胃酸，但机制完全不同，所以不属于同一类。同一类中的多数药物共享后缀与行为，但 opioids 说明大类里也可能有重要例外。[V3]

| 类别 | 词缀 | 例子 | 核心作用 |
|---|---|---|---|
| Beta blockers | -olol | Metoprolol、atenolol、propranolol、nebivolol、timolol | 减慢心率；降低血压 |
| Benzodiazepines | -azepam、-azolam | Diazepam、lorazepam、clonazepam、alprazolam、temazepam | 焦虑、癫痫 |
| Corticosteroids | -asone、pred-、-cort | Prednisone、methylprednisolone、mometasone、fluticasone、hydrocortisone | 抑制免疫反应 |
| Histamine 2 blockers | -tidine | Cimetidine、famotidine、ranitidine | 减少胃酸 |
| Proton pump inhibitors | -prazole | Omeprazole | 减少胃酸 |

词缀与例子来自命名课程。[V3][V20][S26]

学会四类药物的回报很高。识别 beta blockers、benzodiazepines、corticosteroids 与 histamine 2 blockers，就能覆盖约二百种最常处方药中的二十二种。重点不是凭词尾猜出药物的全部性质，而是先认出家族，再去查细节。[V3]


## 6. 细胞受体（Cellular receptors）

人体细胞由 phospholipid bilayer 包裹。脂质尾部靠 Van der Waals forces 相互吸引，头部靠 hydrogen bonding 相连，因此膜既有流动性又能保持完整。膜上嵌有结构蛋白、酶、离子通道、转运载体与 receptors。四类受体中有三类位于细胞表面，作为 transmembrane proteins 贯穿整个膜；第四类位于细胞内。[V6][S16]

Receptor 接收的信号分子叫 ligand，也就是受体天然对应的物质。Ligand 结合后，受体蛋白发生 conformational change（构象改变），这个形状变化启动细胞内的一连串反应。Insulin receptor 是 enzyme-linked receptor 的模型：insulin 结合后受体变形，细胞把更多 glucose transport carriers 放到表面。G-protein-linked receptor 也通过构象改变与 G protein 级联传递信号。Ligand-gated ion channel 的构象改变则是打开一个孔道，让带电离子跨膜。Intracellular receptor 的 ligand 必须脂溶性，才能穿过 bilayer；ligand–receptor complex 进入 nucleus，结合 DNA，改变蛋白质生产。[V6]

| 受体类型 | 位置 | 信号方式 | 模块中的例子 |
|---|---|---|---|
| Enzyme-linked | 细胞表面 | 构象改变；酶级联 | Insulin receptor 增加 glucose transporters |
| G-protein-linked | 细胞表面 | 构象改变；G protein 级联 | 最常见的受体类型；模块未给出具体神经递质例子 |
| Ligand-gated ion channel | 细胞表面 | 打开离子孔道 | 解释 agonism 时用的最简单受体 |
| Intracellular | 细胞内 | Ligand–receptor complex 作用于 DNA | 脂溶性激素 |

四类受体及其信号逻辑是受体课的核心。[V6][S16]

受体数量不是固定的。细胞可以把受体插入膜上，也可以把受体收回，从而改变自己接收多少信息。这就是 opioid tolerance 的机制。当患者连续约三周使用药理剂量的 opioid，细胞会认为刺激过多，把 opioid receptors 从表面拉走、降解，并把零件用于其他用途。受体减少后，同样剂量带来的镇痛下降，患者反而感觉更痛，于是要求更强或更大剂量的药。并非所有受体都会这样代偿，但它解释了许多 rebound 现象，也说明为什么某些药不能超过推荐疗程。[V6]

## 7. 亲和力、效价与选择性

结合并不是简单的“形状对形状”。维持细胞膜的那些力同样维持 ligand 与 receptor 的结合：Van der Waals 吸引、hydrogen bonds 与 ionic bonds，其中 ionic bonding 最强。可以用带磁吸接口的电子设备作类比：配件靠近时被吸过去，“咔”一声固定；要取下时需要一定力量。多数药物与受体的结合是可逆的，但结合的牢固程度差别很大。[V18][S17]

Affinity 就是这种结合强度。高 affinity 的药物在受体上停留更久、更难被拉开；低 affinity 的药物很快脱落。受体在被占据期间持续发出信号，因此占用时间更长可以产生更多信号。[V18]

Potency 是另一个概念：产生特定效应所需的药量。若 A 药三毫克与 B 药三十毫克产生同样效应，A 的 potency 更高。Potency 可以受 affinity 影响，但 affinity 不是唯一决定因素。[V18]

Selectivity 描述药物在不同受体之间的区分能力。Adrenaline 既结合外周血管的 alpha-1 receptor，使血管收缩、血压上升，也结合支气管的 beta-2 receptor，使支气管扩张、气流增加。非选择性 adrenergic 药会两者都做；选择性 beta-2 药正是为了在治疗 asthma 时只扩张支气管，而不收缩血管。反过来，早期 antihistamines 本意是阻断 histamine 1 receptor，却也阻断了 acetylcholine receptor，第二个结合就带来副作用。药物研发不断追求更高 selectivity，因为只结合治疗相关受体，off-target effects 才少。[V18]

Opioid analgesics 同时展示这三个概念。Morphine 与 fentanyl 都结合脊髓的 mu opioid receptor；该处像一个“闸门”，减少传向大脑的疼痛冲动。Fentanyl 的 potency 约为 morphine 的一百倍，因此约百分之一的剂量就能产生相同镇痛。主要原因是 fentanyl 对 mu receptor 的 affinity 强得多，结合更久，产生的信号更多。[V18]

Mu receptor 还有两个亚型，分工不同。Mu-1 负责镇痛；mu-2 负责 respiratory depression、constipation，以及导致成瘾的 euphoria。因此药物研发会追求对 mu-1 的 selectivity 与高 potency，希望在镇痛的同时减少呼吸抑制与成瘾。这就是“为什么要学 selectivity”的实际答案，而不只是背定义。[V18]

## 8. 激动剂、拮抗剂与反向激动剂

在受体上，药物可能做四件事之一。Full agonist 结合后产生与天然 ligand 相同的反应。Partial agonist 结合后产生较弱反应，即使所有受体都被占据，也达不到 full agonist 的最大效应。Antagonist 结合但不产生反应，同时阻止天然 ligand 结合。Inverse agonist 结合后把受体活性降到静息水平以下；只有受体本身具有 constitutive activity 时，这种作用才看得见。[V30][S18]

Ligand-gated ion channel 能把差别显示得很清楚。天然 ligand 结合后，一个 ionic bond 把蛋白的一部分拉成新形状，通道打开，calcium 或其他离子进入。Full agonist 把“门”开到百分之百。形状相同但略大、无法让门完全打开的分子，表现为 partial agonist。形状相同但缺少关键 ionic bond 的分子，结合在同一位置却不引起构象改变，就是 antagonist；由于占据同一位点，它属于 competitive antagonist。大量 antagonist 存在时，天然 ligand 找到受体的机会大大降低。[V30]

Inverse agonist 可以简化为“带有额外抑制作用的 antagonist”。有些受体在未被占据时并非完全沉默，仅因为蛋白存在于膜上就表现出 constitutive activity；inverse agonist 把这条基线压低。并非所有受体都有 constitutive activity，某些 genetic disorders 只对 inverse agonist 有反应，这就是这一类别存在的理由。[V30]

| 药物行为 | 占据受体 | 产生反应 | 增加剂量后的结果 |
|---|---|---|---|
| Full agonist | 是 | 是，最大反应 | 反应上升至受体上限 |
| Partial agonist | 是 | 是，但低于最大 | 反应在低于上限处平台化 |
| Antagonist | 是 | 否 | 阻断更多 ligand；效果取决于 ligand 浓度 |
| Inverse agonist | 是 | 降低 constitutive activity | 基线活动被进一步抑制 |

这张表把“占据”与“效能”分开，是本节课的核心。[V30]

还要尽早分清 inhibitor 与 antagonist。Agonist、antagonist、inverse agonist 描述的是 cellular receptors；inhibitor 描述的是 enzymes。阻断 hydrogen–potassium ATPase 的药是 enzyme inhibitor，不是 receptor antagonist，尽管两者都能阻止某个生理结果。把词汇分开，后面几章就不容易混乱。[V30][V16]

## 9. 洛哌丁胺与阿片类（Loperamide and the opioids）

Opioids 既是一类药物，也是一组内源性神经递质。作为神经递质，它们是神经元之间传递信号的化学信使，可分为 excitatory 与 inhibitory；内源性 opioids 属于 inhibitory，是中枢神经系统的抑制性递质。外源性 opioids 包括 morphine、codeine、heroin、oxycodone 与 tramadol；有些来自 opium poppy，有些是合成物。它们之所以能镇痛，是因为模拟了人体自身的镇痛系统。[V37][S15]

Opioid receptors 并不只分布在疼痛通路。脑内受体介导 euphoria；脑干受体介导 respiratory depression；enteric nervous system 的受体则降低 intestinal motility。这三个位置正好解释了 opioid 的经典作用与副作用：镇痛与欣快、危险的呼吸抑制、以及便秘。[V37]

Loperamide 是 opioid，但在常规剂量下不镇痛、不引起 euphoria，也不抑制呼吸。原因在药代动力学而非受体：它几乎不被吸收。课程给出的数字从约0.3%（“1% 的三分之一”）到“低于0.5%”不等，总之药物主要留在肠道，作用于靠近 lumen 的 enteric nervous system，而不是大脑。[V4][V37][S15]

它的治疗作用是减慢 peristalsis。Peristalsis 是推动肠内容物向前的波浪式肌肉收缩。内源性 opioids 平时就抑制蠕动，让水分有更多时间被吸收，粪便因此更成形。Loperamide 是肠道这些 opioid receptors 的 agonist，所以减慢转运、缓解 diarrhoea。由于使用的是药理剂量，作用比人体自身释放的 opioids 更明显。[V41][S19]

Loperamide 不是唯一选择。多数 opioid 类药物都能减少腹泻，anticholinergic 药物也可用于腹泻。Loperamide 通常更受青睐，因为大部分药物留在 GIT，只局部起效，避免了其他 opioids 的中枢与全身作用。[V41]

滥用会把这个优势反过来。服用推荐剂量三十倍以上，可导致严重便秘、intestinal obstruction、acute peritonitis、住院，以及因 septicaemia 死亡。使用者未必得到想要的 opioid high，却可能死于 fatal arrhythmia，因为高剂量 loperamide 具有 cardiotoxicity。课程还提到，每年有超过十万人死于 opioid overdose，其中许多与超推荐剂量使用 loperamide 有关。本章小结把这些要点压缩在一起：generic names 优先，endogenous opioids 充当 neurotransmitters，而吸收有限正是 loperamide 避开常见 opioid 效应的原因。[V37][V39]

Opioid receptor 也可以被有意阻断。Methylnaltrexone 是吸收极差的 opioid antagonist，几乎是 loperamide 的药理反面。它用于缓解严重的 opioid-induced constipation，例如接受高剂量 opioid 镇痛治疗的 cancer pain 患者；由于它阻断肠道 opioid receptors 且吸收很少，作用基本停留在外周。Naloxone 用于 opioid overdose 伴 respiratory depression。它的结合力强到能把已结合在受体上的 opioid 挤下来，迅速逆转致命效应；但 half-life 很短，在原 opioid 尚未清除前可能需要重复给药。[V41]

## 10. 药代动力学：吸收、分布、代谢与排泄

Pharmacodynamics 问的是“药物对身体做了什么”；pharmacokinetics 问的是“身体对药物做了什么”：如何吸收、分布到哪里、如何代谢、如何排出。希腊词根可以帮助记忆：pharmaco 指药物，dynamics 指力量或效应，kinetics 指运动。[V8][S21]

| 过程 | 回答的问题 | 关键变量 |
|---|---|---|
| Absorption | 药物如何进入血液？ | 给药途径、lipophilicity、表面积、motility、血流、食物 |
| Distribution | 药物去了哪里？ | Protein binding、体液分区 |
| Metabolism | 药物如何被改变？ | 肝脏、cytochrome P450、phase I 与 II 反应 |
| Excretion | 药物如何被清除？ | 肾脏、half-life、反应级数 |

四个过程是本章的骨架。[V8][S21]

### 吸收（Absorption）

Absorption 是药物从给药部位进入 systemic circulation 的过程。给药途径决定路径。口服片剂经 oesophagus 进入胃，崩解后主要在小肠吸收，随后经 portal venous blood 先到 liver，再到右心、肺、左心，最后进入 systemic arterial circulation。Sublingual spray、transdermal patch 或 lower rectal suppository 直接进入静脉系统，在第一次经过肝脏之前就避开 liver。Subcutaneous injection 先进入细胞间隙，再进入静脉血。Inhaled anaesthetic 进入 alveoli，再进入 pulmonary capillaries，只需经过左心就到达体循环。[V34][V35][V36][S22]

唯一不需要 absorption 的途径是 intravenous 与 intra-arterial injection，因为药物直接进入血液，bioavailability 为百分之百。其他途径都会使血浆浓度上升更慢、峰值更低。Peak concentration（Cmax）在口服时低于同剂量吸入或注射；达到峰值的时间也更长。Cmax 越高，过量与副作用风险越大，因为高浓度更容易结合并非治疗目标的受体或酶。浓度在峰值后下降也最快，这对应第一个 half-life。[V36]

胃内吸收很少。即使 aspirin 的化学性质有利于在酸性环境吸收，它在胃内吸收率也不高，因为停留时间短，且胃的表面积远小于肠道。Small intestine 为吸收而特化，villi 与 microvilli 使表面积超过三十平方米，约三百二十平方英尺。[V23]

药物性质也重要。分子大小、酸性或碱性、lipophilicity 都影响吸收。Lipophilic 药物容易穿过 cell membrane，通常吸收更快更完全；hydrophilic 药物可经通道通过，但 lipid bilayer 对它是屏障。这解释了为什么水溶性 cream 主要停留在皮肤局部（皮肤还有 keratin 阻挡），而 transdermal patch 要用 lipophilic 药物，才能穿透到真皮并进入血液。[V23]

生理因素同样重要。GIT 转运越快，接触时间越短，吸收越少。肠道血流影响已吸收药物被带走的速度。进食增加血流，看似应该随餐服药，但食物常降低 bioavailability，即进入体循环的原形药物比例。一般来说，口服药最好在餐前约一小时或餐后约两小时服用。[V23]

### 分布（Distribution）

吸收之后，药物分布在四个主要区间：blood、fat、extracellular fluid 与 intracellular fluid。口服药在到达组织前要先经过 liver，即 hepatic first-pass effect。许多药物还会与 plasma proteins 结合，主要是 albumin 与 globulins；高 lipophilicity 的药物往往结合率也高。[V34][S23]

只有未结合（unbound）的部分能离开血液、到达受体并被代谢。听起来好像高结合率药物大部分无效，但结合是可逆平衡。若百分之八十结合、百分之二十游离，游离部分进入 hepatocytes 被代谢；游离浓度下降后，更多药物从蛋白上解离以恢复平衡。最终所有可逆结合的药物都会变得可用。高结合率药物起效与清除都可能更慢。[V34]

Protein binding 还会造成 displacement interaction。Mrs Ling 原本稳定使用与 albumin 高度结合的 drug A；医生又开了 drug B，B 也与 albumin 高度结合，但 affinity 更强。B 可以把 A 从结合位点挤下来，使 A 的游离浓度升高，可能产生毒性。教科书有时高估这种相互作用的发生率，但它确实存在，也会加重低蛋白患者的 adverse reactions，例如 liver disease 或某些 kidney disease。Liver disease 时更大的问题通常是代谢能力下降，因为 liver 是主要代谢器官。[V34]

### 代谢（Metabolism）

Liver 是药物代谢的主要场所，因为它拥有完整的代谢酶系统，并接收来自 GIT 的全部血液。肠壁等其他组织也参与代谢，但 liver 最重要。代谢的目的不只是“灭活”，而是让分子更 water-soluble，便于 kidney 排泄。在这个过程中，inactive prodrug 可以变成 active drug，active drug 可以变得更强、变弱、失活，或变得更毒。[V35][S24]

代谢分两个阶段。Phase I 主要由 cytochrome P450 enzymes 催化，引入或暴露一个 polar group。这既增加水溶性，也为 phase II 提供“把手”。Phase II 再连接一个极性基团，使代谢物高度水溶、容易排出。若 phase I 后仍太 lipophilic，phase II 就完成剩余工作。[V35]

Aspirin 展示这个顺序。Aspirin 是 prodrug，以 acetylsalicylic acid 形式给药。First pass 时主要先在 liver、少量在 stomach 与 gut wall 转化为 salicylic acid，这是 phase I；随后另一个 enzyme 接上强极性分子，把活性代谢物变成相对 inactive、water-soluble、易排泄的物质。[V35]

First-pass metabolism 解释了几个临床选择。Glyceryl trinitrate 口服 bioavailability 低于百分之一，所以常用 sublingual spray，绕过 liver 迅速进入循环。Morphine 口服 bioavailability 约百分之三十，可以口服，但常静脉给药以获得百分之百 bioavailability。Codeine 是 prodrug，bioavailability 约百分之九十；它本身 inactive，进入 liver 后才转化为 morphine。[V35]

Liver 也可能把物质变得更有毒。Ethanol 首先转化为 acetaldehyde，后者比 ethanol 毒性大得多。因此不能把 liver 的作用简单理解为“解毒”。[V35]

### 排泄与半衰期（Excretion and half-life）

Excretion 是把药物从体内移除，主要经 kidney，也可经 bile 与 faeces；bile 这条路径由 omeprazole 的排泄讨论补充。核心概念是 half-life：体内药物浓度下降一半所需的时间。若中午有八毫克，half-life 为一小时，下午一点约剩四毫克。[V7][S25][V21]

多数药物按 first-order kinetics 消除。单位时间清除的量与浓度成比例，所以计算从剩余量重新开始：两点两毫克，三点一毫克。约四点五个 half-lives 后，通常只剩约百分之五。[V7]

Alcohol 是标准例外。它按 zero-order kinetics 消除，即单位时间清除固定量，而不是固定比例。这发生在剂量大到使代谢酶饱和时。对 alcohol，大约每小时清除一个 standard drink，因此通常不说它有某个“half-life”。Alcohol 还会诱导代谢它的酶，使酶数量增加，所以长期大量饮酒者的清除方式可能与偶尔饮酒者不同。[V7]

算术值得练。若中午有4 mg，half-life 为4小时，下午四点剩2 mg，晚上八点剩1 mg。下降的不是“量”的直线，而是“量的对数”的直线。[V7]

Omeprazole 可以把四个过程串起来。它做成 enteric coated，以便通过胃后在 small intestine 溶解。吸收约需三小时；约百分之九十五与 protein 结合；bioavailability 约百分之六十。First pass 经 liver 的 cytochrome P450 改造。约百分之八十经 kidney 排泄，百分之二十经 faeces，其中一部分是先被送入 bile canaliculi 后排出。Half-life 约一点五小时，但作用可持续七十二小时，原因是它 irreversible 地抑制 proton pump，效应比药物浓度持续更久。[V22][V21][S31]


## 11. H2 受体阻断药与胃酸抑制

Histamine receptors 并不只有一种。H1 receptor 与 allergic rhinitis、眼痒、流鼻水有关，是日常所说“antihistamine”的作用对象；H2 receptor 位于 parietal cell，驱动胃酸分泌；课程还提到第三个亚型。两类主要受体分布在不同器官、承担不同功能，所以选择性作用于 H2 的药不会缓解过敏，选择性作用于 H1 的 antihistamine 也不会减少胃酸。[V13][V26]

Parietal cell 同时受 gastrin、histamine 与 acetylcholine 刺激，而不是只受其中一种控制。三者分别结合各自受体后，hydrogen–potassium ATPase pumps 才开始分泌 protons。Histamine 2 blockers 是 H2 receptor 的 competitive antagonists：占据受体，与 histamine 竞争。Histamine 结合减少，proton 分泌减少，胃酸度下降。[V13][V31]

竞争意味着有“天花板”。即使给予最大剂量，仍会有 histamine 释放并结合部分受体；gastrin 与 acetylcholine 也能通过各自受体驱动 pump。因此 H2 blockers 的抑酸效果约百分之八十，而不是百分之九十九。Proton pump inhibitors 作用于更下游的 pump 本身，可达到约百分之九十九。这就是严重酸相关疾病不以 H2 blockers 为首选机制原因。[V13][V22]

主要适应证是 peptic ulcer disease、GORD，以及胃酸过多的状态。Cimetidine 与 famotidine 都属于二百种最常处方药。[V29]

长期抑制胃酸会产生一组可预测的副作用，因为胃酸有四项工作：开始消化食物、帮助吸收部分营养素、限制随食物进入的微生物、帮助部分药物吸收。长期减少胃酸可能降低 calcium、magnesium 与 vitamin B12 的吸收，增加 GIT 与 respiratory infections，改变部分药物吸收，并因食物蛋白分解不充分而增加 food allergy 风险。课程还提到轻微的心率加快或节律改变风险。Vitamin B12 对老年人尤其重要，因为吸收能力本来随年龄下降，缺乏可引起类似 dementia 的表现；若治疗持续数月，建议监测。Calcium 与 magnesium 的损失则关系到 bone health。[V29][S27]

Ranitidine（商品名 Zantac）曾是使用最广的 H2 blocker，直到2020年发现其中某些成分会分解为 carcinogenic substances。问题随时间加重，储存不当（例如放在炎热的车内）时更明显。原厂商把品牌转向 famotidine，以 Zantac 360 出售。患者若说自己吃“Zantac”，要问清是哪一种制剂，因为柜子里可能还留着旧的 ranitidine。其他 H2 blockers，包括 famotidine 与 cimetidine，都做过相同致癌物检测，未发现同类问题。[S28]

| 特征 | Histamine 2 blockers | Proton pump inhibitors |
|---|---|---|
| 靶点 | Parietal cell 的 H2 receptor | Hydrogen–potassium ATPase pump |
| 机制 | Competitive antagonism | Irreversible enzyme inhibition |
| 最大抑酸程度 | 约百分之八十 | 约百分之九十九 |
| 持续时间 | 较短；取决于药物浓度 | 可达七十二小时，尽管 half-life 很短 |
| 典型定位 | 轻至中度抑酸 | Peptic ulcer disease 与 GORD 的一线治疗 |
| 主要长期顾虑 | 营养吸收、感染、药物吸收 | 同样的酸相关顾虑，另加 CYP interactions |

比较依据 histamine 2 与 proton pump 两节课。[V13][V29][V22]

## 12. 酶抑制与质子泵抑制剂

Enzymes 是催化反应的蛋白质。Substrate 结合到 enzyme 的 active site，发生分子作用，substrate 被切开或转化为 products。没有酶，一个反应可能需要数小时；有酶，反应可在数毫秒内完成。既然酶支撑了如此多生物过程，很多药物通过抑制酶起效就不足为奇。[V11][S32]

Enzyme inhibitors 分两大类。Reversible inhibitors 结合、抑制，然后离开；药物清除后酶功能恢复。Irreversible inhibitors 通常形成 covalent bond，多在 active site，使酶失活，直到药物被降解或细胞制造新的酶。Reversible 是更大的群体，至少分四个亚类；临床上最重要的是 competitive inhibition：药物占据 active site，与 substrate 竞争。增加 substrate 可以克服竞争性抑制。Non-competitive inhibitor 结合在另一个 allosteric site，改变 active site 的形状，使 substrate 无法结合。[V11]

Acetylcholinesterase 是竞争性抑制的教学例子。该酶把 acetylcholine 分解为 acetate 与 choline；一个酶分子每秒可降解约两万五千个 acetylcholine。Competitive inhibitor 占据 active site 期间，降解停止。这在 neuromuscular junction 很关键：acetylcholine 指令肌肉收缩，随后必须被立即清除，肌肉才能舒张。Nerve gases 是同一酶的 irreversible inhibitors；acetylcholine 积聚，肌肉持续收缩，患者因 diaphragm 无法舒张而死于 respiratory distress。Penicillin 则不可逆地抑制细菌有、人类没有的酶，这是 selective toxicity 的基础。[V11]

Aspirin 提出一个表面矛盾。它不可逆地抑制 cyclooxygenase（COX），但抗炎作用只持续约四小时，对 platelet 的作用却持续 platelet 的一生，约九天。血站会询问过去十天内是否用过 aspirin，近期使用者提供的 platelets 不会被采用。解释是 platelet 没有 nucleus，无法转录 DNA 来制造新的 COX；其他细胞可以降解药物并替换被抑制的酶。[V11][S32]

Proton pump 是酶抑制的模型。Hydrogen–potassium ATPase 是 parietal cell 内的大型 transmembrane protein，把 hydrogen ions 泵入胃腔。它既是 pump 又是 enzyme：催化 ATP 转化为 ADP，释放的能量驱动转运。Proton 带电，不能自由扩散，所以必须依赖能量泵。Sodium–potassium ATPase 说明这类泵为何重要：若它停止，sodium 在细胞内积聚，水渗透性进入，细胞破裂。Hydrogen–potassium pump 抑制后较不危险，因为它只在体内两个部位出现，主要在 parietal cell，且并非生存必需。[V31][S33]

Proton pump inhibitors 不可逆地结合 pump。Omeprazole 因此把胃酸分泌降低约百分之九十九。它的 half-life 只有约一点五小时，作用却可持续七十二小时，因为酶在被替换或被降解前一直失活。这就是为什么每天一次即可，尽管药物清除很快。药物只抑制当时正在分泌的 pump，所以应空腹服用，并在约三十分钟至一小时后进食，让 pump 在药物仍存在时被激活。[V22][V31][V21]

Omeprazole 用于 GORD、peptic ulcer disease 与胃酸过多的状态，并且是 peptic ulcer disease 与 GORD 的一线治疗。它被列入 World Health Organization 的 essential medicines list，在部分国家可非处方购买。常见副作用是 nausea、vomiting 与 intestinal gas 增多。较少见的是 GIT infections 与 pneumonia 增加，因为胃酸是阻挡随食物进入及增殖的微生物的屏障；长期使用还通过减少 calcium 与 magnesium 吸收而增加 bone fracture 风险。[V17][S35]

适应证本身也带有安全问题。患者可能说自己只是 GORD，实际却是 Barrett's oesophagus，即食管黏膜的癌前改变。此时停用抑酸药，胃酸会继续溅在已发生 dysplasia 的细胞上，可能进展为 oesophageal cancer。Peptic ulcer 还可能侵蚀到 artery，向胃内出血。因此，不能因为患者口述的诊断听起来“良性”就建议停药；完整病史应由 prescriber 评估。[V17][V9]

Pregnancy categories 是另一层安全信息。课程描述的澳洲系统中，category A 最安全，预计不会对胎儿产生不良影响；category D 则可能有害到让育龄女性即使没有怀孕计划也需要停药；一份课程材料把 D 与 E 归为一组，另一份则称 D 是最差类别、X 肯定致畸。模块文件把 omeprazole 列为 pregnancy category B3，视频则说澳洲为 B、美国为 C；这提醒不同国家的分类体系不同，必须使用所在地的系统。[S35][V17][V9]

Omeprazole 还抑制 liver enzymes，具体是 CYP2C19 与 CYP2C8。这意味着它可以升高或降低经这些酶代谢的其他药物浓度。临床规则不是背下所有配对，而是看到 CYP interaction 就查药物手册。Grapefruit juice 是食物中的典型例子：它强烈抑制 CYP3A4，而该酶参与代谢市场上超过一半的药物；即使二百毫升果汁或一个水果，也可能产生临床显著影响。抑制可增强或减弱药物作用，取决于该酶是在激活 prodrug，还是在灭活 active drug。另一些药物是 inducers，会指示肝细胞制造更多酶，从而降低其他药物浓度。[V43][S34]

COX 例子说明酶抑制为何会产生“靶外”伤害。NSAIDs 与 aspirin 抑制 COX 以减轻炎症，但 COX 在 stomach 与 kidney 还有保护作用。长期使用去掉这层保护，促成 stomach ulcers 与 kidney damage。Omeprazole 避开这个问题，因为它的靶酶几乎只存在于 parietal cell，所以 adverse-effect profile 相对较好。[V43]

| 特征 | Reversible inhibition | Irreversible inhibition |
|---|---|---|
| 化学键 | 通常非共价 | 通常共价 |
| 持续时间 | 直到药物清除 | 直到酶被替换或药物被降解 |
| Substrate 竞争 | 可克服 competitive inhibition | 不能克服 |
| 例子 | Competitive acetylcholinesterase inhibitor | Omeprazole 作用于 proton pump；aspirin 作用于 COX |
| 临床后果 | 可从药物浓度预测 | 效应超过 half-life |

这个对比解释了为什么 omeprazole 用短 half-life 的药物却能维持一天以上。[V11][V31][V9]

## 13. 神经传递与止吐药（Antiemetics）

Vomiting 的控制中枢在 brainstem 的 medulla oblongata。胃常常是信号来源，但不是控制中心。四条 neural pathways 汇聚到 vomiting centre，每条使用不同的 neurotransmitters。这就是为什么一种 antiemetic 不能解决所有类型的呕吐。[V42][V12]

四条通路分别是：从 GIT 到 vomiting centre，见于肠道受损或受刺激；从 chemoreceptor trigger zone（CTZ）到 vomiting centre，见于毒素或化学失衡；从内耳 vestibular apparatus 到 vomiting centre，见于 motion sickness；从 cerebral cortex 到 vomiting centre，见于情绪性或高级脑功能相关的呕吐。CTZ 紧邻 vomiting centre，但在 blood–brain barrier 之外，因此可以“采样”血液中的化学物质。[V12][V2]

| 通路 | 触发因素 | 主要 neurotransmitters | 首选药物类别 |
|---|---|---|---|
| Cerebral cortex | 情绪、焦虑、皮质损伤 | 模块未进一步细分 | Benzodiazepines |
| Vestibular apparatus | 运动、内耳紊乱 | Histamine 1、acetylcholine | 能进入脑内的 antihistamines；anticholinergics |
| GIT | 黏膜损伤、刺激、chemotherapy | Serotonin 3（5-HT3）、dopamine 2 | 5-HT3 antagonists；dopamine 2 antagonists |
| Chemoreceptor trigger zone | 毒素、glucose、电解质或 pH 失衡 | Serotonin 3、dopamine 2 | 5-HT3 antagonists；dopamine 2 antagonists |

通路—递质—药物的对应关系是本章的组织框架。[V12][V10][V2]

安全评估先于选药。反复呕吐会排出 hydrogen ions，身体可能变得过碱，形成 metabolic alkalosis，同时伴 dehydration 与 electrolyte loss；这些失衡可引起神经系统症状并迅速恶化。病因同样重要。Intestinal obstruction、appendicitis、gallstones 与 perforated bowel 都会引起呕吐，而止吐药不会解决其中任何一个。GIT 之外，新诊断 type 1 diabetes 的儿童血糖升高会被 CTZ 感知，呕吐可能是首发症状；ketones 会让呼吸和尿液带甜味。Kidney failure 的毒素、pH 异常与 thyroid disease 也可能以呕吐起病。一个连续两天早餐后呕吐的青少年需要验血，而不是胃药。[V19][S38][S43]

理解止吐药要先理解 neurotransmission。电冲动传到 axon terminal，vesicles 与膜融合，把 neurotransmitter 释放到 synaptic cleft。递质越过狭窄间隙，结合下一个神经元的 receptor。Excitatory transmitter 让下一个细胞更可能 depolarise；inhibitory transmitter 则相反。信号强弱不是靠单个冲动的大小，而是靠冲动频率。递质随后必须被迅速清除，否则无法区分前后信号；清除方式有两种：cleft 中的 enzyme 降解，或 reuptake pump 回收。[V14][S42]

药物可以干扰其中任何一步：阻断 receptor（antagonist）、模拟递质（agonist）、抑制降解酶、阻断 reuptake pump。Antiemetics 多属第一类：它们是针对该通路递质的 receptor antagonists。副作用通常来自同一受体在“不该被阻断”的部位也被阻断。[V14][S42]

### 晕动病与前庭通路

Vestibular pathway 使用 histamine 1 与 acetylcholine。因此药物必须阻断其中至少一种受体，并且必须进入脑内才能到达该通路。最有效的非处方选择是能进入中枢的 antihistamines，如 diphenhydramine 与 dimenhydrinate，以及 anticholinergic 的 hyoscine（也称 scopolamine）。[V12][S39]

能穿过 blood–brain barrier 的 antihistamines 会引起 drowsiness 与 coordination 下降，因为 histamine 在脑内参与维持觉醒。它们还带一点 anticholinergic 作用。Anticholinergics 阻断 parasympathetic 的“rest and digest”系统，减少 GIT 运动与分泌，包括唾液，所以 dry mouth 很常见。对于既有 motion sickness 又有肠道痉挛的旅行者，hyoscine 因而很合适。[V12]

Selectivity 解释了 loratadine 的不同。Loratadine 主要停留在脑外，因此缓解过敏而不引起嗜睡，但也因此对 motion sickness 无效。H1 receptors 不参与其他呕吐通路，所以 antihistamines 对来自 GIT、CTZ 或 cortex 的呕吐帮助很小。[V12]

钓鱼情境把配对讲得很具体。Joel 有严重 hay fever，负责开船，且从不晕船；他应使用 loratadine，因为镇静性 antihistamine 会损害驾驶能力。Alma 当天有肠道痉挛与稀便，偶尔晕船；hyoscine 同时处理 vestibular pathway 与肠道过度活动。Vivon 很容易晕船，没有其他问题，也不开船；出发前约一小时用 diphenhydramine 合适，但要预期可能嗜睡。[V12]

### 化疗与 GIT 通路

GIT 与 CTZ 两条通路在多个关键点共用 serotonin 3，写作 5-HT3。因此 5-HT3 antagonist 是强效止吐药，ondansetron、dolasetron 及其他“-setron”药物对 chemotherapy-induced vomiting 尤其有价值。由于 5-HT3 在这些通路之外使用很少，这类药副作用相对较少；主要缺点是价格高。[V10][S45]

Dopamine 2 是另一条共用递质。Dopamine 2 antagonists 对 GIT 刺激引起的呕吐有效，对 CTZ 刺激也有一定效果。代表药是 prochlorperazine 与 metoclopramide。它们便宜，但副作用比 5-HT3 antagonists 多，因为 dopamine 2 遍布脑内，多数 antipsychotic drugs 也是 dopamine antagonists。Dopamine 阻断相关的 involuntary movement disorders 是主要顾虑。[V10]

化疗情境把逻辑串起来。James 正在接受 chemotherapy，药物损伤胃黏膜，产生大量来自 GIT 的信号；化疗药也被 CTZ 感知，另有一路信号传向 vomiting centre。Bismuth subsalicylate 只局部抗炎、减少胃酸，可能舒缓胃部，但不能止吐。Diphenhydramine 针对内耳性呕吐，无效。Hyoscine 对 motion sickness 与肠道痉挛有效，对化疗无效。Lorazepam 属 benzodiazepines，只对 cortical emesis 有效，有时作为辅助，但不能单用。Metoclopramide 因价格低可能先试用，剂量往往较高，但患者可能无法耐受 movement side effects。Ondansetron 最有效且耐受最好，因为 5-HT3 是 GIT 与 CTZ 两条通路的核心。[V10]

Bismuth subsalicylate 需要单独说明。它不是 receptor 意义上的 antiemetic，不作用于 neural pathways，而是直接作用于肠道，具有局部抗炎、降低胃酸与直接抗菌作用，可缓解轻度胃部刺激。它在澳洲不出售，所以模块只要求了解其适应证与效果；在其他国家它很常见，也被许多经常胃部不适的人大量使用。[V42][S41][S37]

Benzodiazepines 是 cortical pathway 的选择。Cortex 到 vomiting centre 的通路参与情绪性呕吐，而以 -azepam 或 -azolam 结尾的 benzodiazepines 作用于该处。二百种最常处方药中有五种属于这一类。[V12]

两个 Panopto 总结把同一张地图压缩了一遍。一个讲 quiz 背后的学习策略；另一个复习 vomiting centre、四条输入通路以及递质与药物的对应，包括用 antihistamines 与 anticholinergics 处理 motion sickness、用 ondansetron 处理 chemotherapy。[V1][V2]

## Key takeaways

1. Antacids 只中和已经存在的胃酸，适应证是偶发 heartburn；慢性反流属于 GORD，需要评估，因为 dysplasia 可进展为 oesophageal cancer。[S3][V25]
2. Magnesium antacids 通过渗透活性的 magnesium chloride 引起腹泻；aluminium antacids 引起便秘并结合药物；sodium bicarbonate 增加盐负荷；calcium carbonate 的 rebound 最强。[V44]
3. Rebound hyperacidity 是 homeostasis 的体现：降低胃酸会触发代偿性分泌增加，diuretic tolerance 也遵循同一逻辑。[V38]
4. Constipation 由 Rome criteria 定义，不由“感觉”定义；laxatives 排在水、纤维与 psyllium 之后。[V28][V15]
5. Osmotic laxatives 呈 linear dose response，并在 obstruction 中禁用；多数药物（包括 paracetamol）并非如此。[V33]
6. Stimulant laxatives 只用于偶发便秘或肠道准备，可造成 rebound constipation、永久性结肠损伤与电解质丢失。[V24]
7. Mineral oil 与 detergent softener 合用属于 strictly contraindicated，因为被吸收的油无法排出并会引发 granuloma。[V40]
8. Receptor 把 ligand 结合转化为细胞反应；affinity 是结合强度，potency 是所需剂量，selectivity 是受体区分能力。[V18]
9. Loperamide 是留在肠道的 opioid agonist，常规剂量下不镇痛、不欣快、不抑制呼吸；高剂量可致 obstruction 与 arrhythmia。[V41][V37]
10. Pharmacokinetics 就是 ADME；first-pass metabolism、protein binding 与 half-life 解释许多临床决策，alcohol 是 zero-order 的经典例外。[V35][V34][V7]
11. Histamine 2 blockers 属竞争性，抑酸约百分之八十；proton pump inhibitors 不可逆抑制 pump，抑酸约百分之九十九，作用可达七十二小时。[V13][V22]
12. 止吐药按通路选择：vestibular 用 antihistamines 或 anticholinergics，chemotherapy 与 GIT/CTZ 用 5-HT3 antagonists，GIT 刺激用 dopamine 2 antagonists，cortical 用 benzodiazepines。[V12][V10]

## Common confusions

**Antacid、H2 blocker 与 proton pump inhibitor 不能互换。** Antacid 中和已经存在的酸；H2 blocker 在受体层面减少 histamine 驱动的分泌；proton pump inhibitor 阻断最终的 pump。三者起效速度、抑酸程度与持续时间不同，只有后两类用于慢性酸相关疾病。[V25][V13][V31]

**Affinity、potency 与 selectivity 是三个不同的测量。** Affinity 是结合多紧；potency 是需要多少药；selectivity 是避开其他受体的程度。结合很紧的药未必选择性高，选择性高的药也未必 potency 高。[V18]

**Pharmacodynamics 与 pharmacokinetics 问的是相反的问题。** 前者是药物对身体做了什么，后者是身体对药物做了什么。受体结合属于 pharmacodynamics；吸收、分布、代谢、排泄属于 pharmacokinetics。[V8]

**First-order 与 zero-order 的算术不同。** First-order 每个 half-life 清除固定比例，数量按 8、4、2、1 下降；zero-order 每小时清除固定量，如 alcohol，因为酶已饱和。[V7]

**Generic name 与 brand name 提供的信息不同。** Brand 是商业标签，可以有上百个；generic name 是发药标签上的稳定名称，常含类别词缀。先记 generic。[V20]

**“Contraindicated”比“strictly contraindicated”轻。** 前者是“除特定情形外避免”，后者是“永远不能合用”，如 mineral oil 与 docusate。[V40]

**Osmotic 与 stimulant laxatives 的物理机制不同。** Osmotic 把水拉进肠腔，呈 linear dose response；stimulant 刺激肠道、增加蠕动与分泌，代价是 rebound 与结构损伤。[V33][V24]

**H1 与 H2 receptors 不能混用。** “Antihistamine”习惯上指用于过敏的 H1 blocker；H2 blocker 减少胃酸。吃 H2 blocker 不会缓解过敏，吃 H1 antihistamine 也不会治疗反流。[V26]
