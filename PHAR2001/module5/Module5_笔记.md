# PHAR2001 — Module 5: Analgesics and psychotropic medicines / 镇痛药与精神神经药物

以下为依据课程档案整理的 AI 辅助复习摘要，不是逐字稿、临床操作规范或作业答案。须结合原文、阅读资料及当期 unit outline。保留选学内容不代表全部必考。

**用药安全：**仅供学习，不提供处方建议。临床应用须核对最新权威药物资料。源课文有旧版考核百分比或陈述，原文如实保存，不代表摘要为其背书。

## 疼痛与炎症

区分急性保护性疼痛、慢性疼痛与神经病理性疼痛，解释炎症及敏化进入通路的位置。联合用药应按机制和安全性理解，不能假定两个产品必然优于一个。

## 非阿片镇痛

比较 NSAID/COX 相关作用与 paracetamol 的作用和局限；有退热或镇痛效应不代表抗炎效应相同。课程特别强调儿童和老年人的风险背景。

## 阿片类

将受体作用与镇痛、镇静和呼吸影响等风险联系起来，区分急性疼痛与慢性/神经病理性疼痛的不同问题。具体阿片药物扩展课标为选学，仍保留。

## 精神神经主题

包括 Parkinson、Alzheimer、焦虑与抑郁。先理解疾病与递质通路，再比较药物；benzodiazepines 与替代药在目标、风险和依赖性方面不同，不能把所有镇静药视为同类。

## 抗抑郁及选学

比较 SSRI、TCA、SNRI 和 atypical antidepressants 的递质靶点与安全问题。原文把精神病、具体抗精神病药与抗癫痫章节标为 non-compulsory，档案中均保留。

## 复习自测

解释 paracetamol 与 NSAID 的差异；把阿片作用映射到安全风险；比较 SSRI 与 SNRI；分析年龄、合并药物及器官功能如何改变风险。临床使用须核对现行权威药物资料。

## 机制与安全对照

| 药类/主题 | 学习时的关键区分 | 安全重点 |
|---|---|---|
| NSAIDs 与 paracetamol | 止痛、退热并不代表抗炎作用相同 | 核对重复成分、器官风险及超量危害；止痛不足不能成为随意加量的理由 |
| 阿片类 | 受体介导止痛，同时影响其他组织 | 将镇静、呼吸抑制与肠道效应联系机制，考虑与其他镇静药的叠加 |
| Parkinson’s / Alzheimer’s | 病变神经通路不同，治疗机制也不同 | 区分改善症状与治愈/阻止进展；旧资料中的治疗陈述不等于最新治疗综述 |
| 苯二氮卓与替代药 | 不同药物半衰期及用途不同，buspirone 不是另一种 benzodiazepine | 考虑蓄积、依赖与镇静；原页保留了教师对药物分级表述的更正 |
| 抗抑郁药 | SSRI 主要抑制 serotonin 再摄取；SNRI 涉及 serotonin 与 noradrenaline；TCA 与非典型药还有其他差异 | 从原材料比较靶点、起效预期、相互作用及副作用，不把所有抗抑郁药视为可互换 |
| 精神病与癫痫 | 延伸受体/神经机制 | psychosis、specific antipsychotics、seizures 在源课中属选学，已保留 |

## 临床推理复习

解释同时使用多个镇静产品的老年人与只使用一种药的年轻人，为何安全评估不同。比较药物的预期症状收益与负担，区分急性疼痛、炎症性疼痛与神经病理性疼痛。以上是学习推理，不是个体处方建议。
