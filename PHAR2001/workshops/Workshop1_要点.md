## 3. Quiz（20%，11 月 6 日周五）

**结构**（讲师凭记忆，下周确认）：32 道选择题 × 0.5 分 = 16 分，2 道简答 × 2 分 = 4 分，共 20 分。线上自动评分。测验前会先放几道练习题让你熟悉界面。

**范围：** Module 1 全部 + orientation 里 Ken 讲的三段内容（1–2 题）。**Module 2 不考**。

### 题型陷阱（这场 workshop 最值钱的部分）

1. 题干常写成 *which of the following statement(s) is/are correct / incorrect* —— 是**多选**，逐条判断，不是选一个最佳答案。
2. 很多题里**大部分选项本身都是正确陈述**，考的是"挑出那一条错的"。所以习惯是：先把每个选项当判断题做，再决定勾哪几个。
3. 会出现 *all of the above are correct* / *none of the above are incorrect* 这类兜底选项，必须真的读完 A–E 才能选。
4. 漏选按整题错处理——线上自动判分，选了 2 个正确项、漏掉第 3 个，这题 0 分。**按"漏选即全错"来准备，不要赌部分分。**
5. 时间够用（讲师反复强调），但必须留出读题时间：这是新学的专业语言，一字之差（more/less likely）就是答案。

### 备考方法

- 把 Module 1 每个 activity 重做一遍；注意题目下方的小圆点——有几个点就是几页题，逐页做完。
- **做对了也要读 feedback**，那里常有延伸解释（她现场就示范了 loperamide 那条）。
- 答错的那几题单独记下来，考前只看这些。

## 4. 三道真题（现场讲解的答案逻辑）

### ① Loperamide（洛哌丁胺）

选项：平均只有 1/3 的 1% 被吸收 / 作为阿片类药物可用于止痛 / 它是一种阿片类药物 / 作用于 GIT 的阿片受体。答案：**1、3、4 正确**。

要点：它的确是阿片类，但全身吸收极少（正常剂量下基本留在肠道），只作用于肠壁神经元止泻，进不了中枢，**不能止痛**。"是阿片类 → 能止痛"是典型陷阱（把药理分类直接推成临床用途）。

### ② Cmax（峰值血药浓度）

选项：给药途径造成很高 Cmax 会让药物在代谢初期被更快代谢 / 入血最快的给药途径，过量、副作用与并发症风险最大 / 定义（Cmax = 达到的最高/峰值血清浓度）/ 浓度高时更不容易与"不该结合"的受体或酶结合。答案：**1、2、3 正确，4 错**。

要点：4 反了——浓度越高，越容易脱靶结合到别的受体或酶，副作用与毒性风险随之升高。这类题先找定义句（往往排在后面），确认它正确，再用它去校准其他选项。

### ③ 吸收与生物利用度

选项：与食物同服通常会降低生物利用度 / 即使药物性质适合胃内吸收（如阿司匹林），胃里实际吸收的量也很少 / 软膏是油基外用制剂，若需吸收，药物必须是脂溶性 / 亲水（水溶性）药物是 GIT 吸收最好的一类。答案：**1、2、3 正确，4 错**。

要点：

- 食物降低生物利用度的机制：食物占据肠腔容积，药物要"挤过去"，容易错过吸收窗口，吸收变慢、进入体循环的量减少。
- 胃的吸收面积小、停留时间短，即使药物在酸性环境稳定，实际吸收仍以小肠为主。
- **脂溶性（lipophilic）药物吸收最快**——可直接穿过肠上皮细胞膜；**亲水（hydrophilic，水溶性）药物反而需要通道或转运体**，所以不是"吸收最好"。

术语要能中英互认：lipophilic = 脂/脂溶性，hydrophilic = 亲水/水溶性，bioavailability = 生物利用度（到达体循环的原型药物比例），Cmax = 峰值血药浓度。

## 5. Workbook（30%，第 5 周周三）

**只答两题**：Part B 必答，A 与 C 二选一。题目在第 3、4、5 周的 tutorial 里现场给出——也就是说，不参加（或不看录播）就拿不到题。

**做法（她给的工作流，几乎等于标准答案流程）：**

1. 进 tutorial 前就把模板打开、存好。
2. 题目出现在 chat 里时，直接复制题干粘进模板。
3. Ken 讲答题思路时，边听边把要点打进题目下方的空格。
4. 课后补研究、补引用、润色；目标 HD 就多花一点。
5. 一题基本可以在一周内收尾。

**硬性要求：**

- **绝不能交 dot points。** 点列 = 直接 fail。必须写成完整句子和段落——评估的是"能否用专业语言与同事、病人沟通"。
- 引用框里有内容才计分；workbook 的答案主体来自 tutorial，额外补充的外部信息必须引用。
- 自己的话写。多人协作痕迹、改写不到位的段落，Turnitin 会查出来。

## 6. Case study（50%，第 6 周周五）

**结构：** 5 个部分 A–E，分别对应 Module 2、3、4、5、6。**从第 2 周就开始**，每周推进一个部分，约 2 小时/周——趁模块内容还热的时候写。

**形式：** 给一个病例情境（例如 3 岁男孩或 70 岁男性，带着症状和一份用药清单来诊），随后是一串简答题：病理生理、某个药的药代动力学、安全性等，在每题下方的框里作答。本质是"围绕情境的一系列简答"。

**引用规则（最容易被扣分的地方）：**

- 每题**最多 2 条**引用（可以反复用同一本，如 Bullock《Fundamentals of Pharmacology》）。
- APA 7 或直接粘 URL 都行，**格式不影响分数**；但引用框空着，这道题直接 0 分——"marker 根本不看没有引用的答案"。
- **不许引用 module 或 workshop。** 任务设定是：你在一个多学科诊所里，同事都很忙，你要用最可靠、最新、最安全的资料回答病人和同事的问题。所以必须用外部学术来源——第 1 周 tutorial 讲的就是怎么找。
- 必须填写是否使用 AI 的声明。

**字数：** 建议值不是硬上限，但不得超过建议值的 **150%**。例：建议 50 词 → 上限 75 词；超了说明你在写不相关的东西。

**评分取向：** 先读 brief 和 rubric，往 HD 那一档写——覆盖安全议题、理解有深度、没有半截答案、信息准确且是最新的、每题都有引用。Fail 档的特征就是：缺引用、表达不清、信息不准确。

**学术诚信：** 不要对着 tutorial 录播逐句暂停抄 Ken 的讲解。看懂了，用自己的话重写，Turnitin 相似度才不会失控。
