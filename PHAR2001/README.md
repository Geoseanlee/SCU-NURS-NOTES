Scraped from Southern Cross University Blackboard Ultra on 2026-11-05.

## Layout

Each numbered folder is one top-level item from the Ultra course outline
(modules, orientation, assessments, tutorials, workshops...).

```
06 - Module 1- .../
  material/*.epub        Blackboard Ally ePub for each document
  html/*.html            same document as HTML (keeps video/link markup the ePub drops)
  files/                 original attachments (PDF/DOCX/PPTX)
  extracted_content.txt  text extracted from the ePubs (same method as extract_all.py)
  structure.md           item tree for this section
  videos.md              videos in this section, with summaries
```

Also:

- `documents.json` — every document, its section and breadcrumb path
- `VIDEOS.md` — video index for the course
- `../videos/` — Panopto delivery metadata, YouTube metadata, caption transcripts
- `../video_jobs.json`, `../resolved.json` — scrape provenance

## Videos

| Source | Count | What was captured |
|---|---|---|
| Panopto | 122 | Panopto's own AI summary, key points, chapters, duration |
| YouTube | 106 | title, channel, description, auto-caption transcript |

The ePub export omits anything embedded in a video, which is why the HTML copy
and the Panopto/YouTube capture exist alongside it.

Notes:

- Panopto summaries are generated by Panopto's AI from the audio track; they are
  not hand-written notes.
- YouTube transcripts are auto-generated captions, so wording/terms can be off.
- `html/` keeps the original embed markup. Playing a video from the saved file
  still needs an active SCU login (the links go to Panopto/YouTube).

## Reproduce

```bash
python3 scrape_scu.py        # requires an authenticated cookie export
node resolve.mjs ...         # resolves Panopto LTI links to session ids
python3 fetch_youtube.py     # yt-dlp metadata + captions
python3 extract_epubs.py ~/scu_export
python3 enrich_videos.py
```
