## 1. 病情恶化识别框架 (Recognising Deterioration: Clinical Frameworks)

### Between the Flags (BTF)
NSW Health 的病情恶化"安全网"系统，用**颜色编码的"track and trigger"图表**来识别早期预警信号并标准化上报流程。

- 🟡 **黄区 (Yellow Zone)** = 临床复查 (Clinical Review)
- 🔴 **红区 (Red Zone)** = 快速反应 (Rapid Response)
- 标准化呼叫标准 (calling criteria)
- 支撑 NSQHS 的"识别与应对急性病情恶化标准"

图表分纸质版和电子版（NSW 公立医院用 Cerner eMR 系统），停机时使用纸质版。

### A-G Assessment（快速全身评估）
系统化的快速患者评估方法，帮助护士**尽早发现危及生命的问题**并在处理后再进行下一步。

重要性：
- 为紧急情况提供结构
- 帮助早期识别病情恶化
- 与生命体征解读直接相关
- 培养临床推理能力

> 完整的 A-G 评估将在 NURS2004 / NURS5012（全生命周期健康评估）中学习，本模块仅介绍基础概念。生命体征的测量顺序遵循 **SAGO 图表**顺序，并与 A-G 框架对齐。

## 3. 呼吸 (Respiratory Rate)

### 生理学
呼吸包含以下过程：
- **肺通气 (Pulmonary ventilation)** — 空气进出肺部
- **吸气 (Inspiration)** / **呼气 (Expiration)**
- **外呼吸 (External respiration)** — 肺泡与血液间的气体交换
- **内呼吸 (Internal respiration)** — 血液与组织间的气体交换

### 呼吸评估（对应 A-G 中的 A&B）
计数呼吸前的简要评估：
- 听呼吸音
- 观察胸廓运动
- 识别正常 vs 异常模式
- 注意呼吸做功情况

### 呼吸模式术语
| 术语 | 含义 |
|---|---|
| Eupnoea | 正常呼吸 |
| Tachypnoea | 呼吸过快（>20 次/分） |
| Bradypnoea | 呼吸过慢（<10-11 次/分） |
| Dyspnoea | 呼吸困难/气短感 |

### 影响呼吸频率的因素
- 急性疼痛 → ↑频率、↓深度
- 年龄 — 新生儿 30-60 bpm；成人 12-20 bpm
- 脑损伤 — 可改变频率与深度
- 运动 → ↑频率与深度
- 性别 — 男性多用膈肌，女性多用肋间肌

### 测量方法
**必须完整计数满 1 分钟**，同时评估：
- 胸廓起伏
- 对称性
- 是否使用辅助呼吸肌
- 呼吸做功
- 是否有异常呼吸音

### 文档记录
- 记录在 SAGO 图表的 **Airway/Breathing** 部分
- NSW 和 QLD 图表版本不同（模块中都有展示）
- 可纸质或电子（eMR）记录
- **呼吸频率记录是临床技能考核（Clinical Skills Assessment）的必考项**

## 4. 血氧饱和度 (Oxygen Saturation, SpO₂) 与脈搏血氧仪 (Pulse Oximetry)

### 关键概念
- **通气 (Ventilation)**：吸入 O₂ 呼出 CO₂
- **弥散 (Diffusion)**：气体沿浓度梯度移动（高→低）
- **灌注 (Perfusion)**：向组织输送含氧血液，依赖足够心输出量
- **低氧血症 (Hypoxia)**：组织内氧含量过低

**低氧常见征象：** 心动过速、焦虑/躁动不安、苍白或发绀（晚期征象）、呼吸做功增加、呼吸过速

**可能影响氧合的疾病：**
- 阻塞性肺疾病：哮喘、肺气肿、慢性支气管炎
- 限制性肺疾病：肺炎、肺纤维化
- 弥散障碍：肺气肿、肺水肿
- 通气/灌注不匹配：右心衰、肺动脉高压

### 血氧饱和度定义
血氧饱和度 = **携带氧气的血红蛋白百分比**
- 类比：血红蛋白="车"，氧气="乘客"，血管="路"
- 16 个血红蛋白单位中有 8 个载氧 → 饱和度 50%
- "正常值"因人而异，需结合患者病史与基线判断

### 脉搏血氧仪工作原理
利用光吸收原理计算 SpO₂：
- 光从探头发射端 → 穿过手指 → 到达检测端
- 含氧血红蛋白与去氧血红蛋白吸光特性不同
- 仪器分析吸光差异得出 SpO₂

**优点：** 无创、便宜、便携、能比可见发绀更早发现低氧血症

**影响准确性的因素：**
- 灌注不良
- 指甲油/义甲
- 移动
- 肢端冰冷
- 一氧化碳中毒
- 探头放置不当

### 文档记录
- SAGO 图表 Airway/Breathing 部分下有 Oxygen 一项
- 本单元不进行氧疗，需在 device/mode 处填写 **"RA"（Room Air，室内空气）**
- **属于 SAGO 图表和临床技能考核的必考项**

## 5. 血压 (Blood Pressure, BP)

### 基础概念
血压 = 血液在动脉壁上施加的压力，包含两个成分：
- **收缩压 (Systolic)** — 心室收缩时的压力
- **舒张压 (Diastolic)** — 心室舒张时的压力

单位：mmHg，记录方式：收缩压/舒张压（如 120/80 mmHg）

### 生理调节
血压受以下因素影响：
- 心输出量 (cardiac output)
- 血容量 (blood volume)
- 外周血管阻力 (peripheral vascular resistance)
- 动脉弹性 (arterial elasticity)
- 血液粘度 (blood viscosity)

### 正常与异常范围
| 分类 | 收缩压 | 舒张压 |
|---|---|---|
| 正常成人 BP | 90–119 mmHg | 60–79 mmHg |
| 血压升高 (Elevated) | >120/80 mmHg | — |

血压持续升高会增加：高血压、心脏病、卒中风险

### 影响血压的因素
| 不可调节因素 | 可调节因素 |
|---|---|
| 年龄 | 吸烟 |
| 遗传 | 饮食 |
| 家族史 | 运动量 |
| | 压力 |
| | 饮酒 |
| | 肥胖 |

### 测量评估
所需设备：血压计 (sphygmomanometer)、听诊器、正确尺寸的袖带

**关键步骤：**
1. 手部卫生
2. 患者体位摆放舒适
3. 定位肱动脉或桡动脉搏动
4. 正确佩戴袖带
5. 以正确速率充气/放气
6. 识别柯氏音 (Korotkoff sounds) 判断收缩压/舒张压
7. 立即记录

> 本模块推荐使用**桡动脉 (radial)** 定基线（视频中用肱动脉也可以，两者皆可接受）

### 术语补充
- Hypertension（高血压）/ Hypotension（低血压）/ Normotensive（血压正常稳定）
- Korotkoff sounds（柯氏音）：听诊血压时听到的五个不同阶段的声音

### 文档记录
- 记录在 SAGO 图表的 **Circulation** 部分
- NSW/QLD 图表不同
- 测量后立即记录
- **血压记录是临床技能考核的必考项**

## 6. 脉搏/心率 (Pulse / Heart Rate)

### 生理学
脉搏 = 左心室收缩、血液被泵入动脉系统时，在外周动脉触及或心尖听到的搏动感。
脉搏 = 心率 → 每分钟心脏搏动次数（因人而异，需了解患者基线）

### 评估要素
| 要素 | 说明 |
|---|---|
| **频率 Rate** | 每分钟搏动次数；成人正常范围 **60–100 bpm**（本模块采用此范围） |
| **节律 Rhythm** | 规律或不规律；不规律 = 心律失常 (arrhythmia) |
| **强度/容量 Volume** | 每次搏动的力度：bounding（洪脉）、strong、weak、thready（细弱） |

### 影响脉搏的因素
运动、发热、疼痛、焦虑、药物、出血、年龄、体温、疾病过程 (Beale & Nanayakkara, 2018)

### 脉搏触诊部位
- **桡动脉 (Radial)** — 成人及 >12 个月儿童最常用
- **肱动脉 (Brachial)** — 用于测血压
- **颈动脉 (Carotid)** — 紧急情况
- **股动脉、腘动脉、足背动脉、胫后动脉** — 评估下肢循环
- **心尖搏动 (Apical)** — <12 个月婴儿或节律不规律时听诊

### 桡动脉触诊技术（一年级学生用触诊法评估）
- 用 **2-3 根手指**（绝不用拇指——拇指有自己的脉搏！）
- 轻柔施压
- 完整计数 1 分钟
- 评估频率、节律、强度

**为什么用 2-3 指而不用拇指？**
- 单指压力过大易堵塞
- 中指感知脉搏
- 第三指帮助排除尺动脉干扰
- 拇指因自身有搏动而避免使用

### 术语
- Tachycardia（心动过速，>100 bpm）
- Bradycardia（心动过缓，<60 bpm）
- Atrial fibrillation（心房颤动——不规律且常偏快的心律，属心律失常）

### 文档记录
- 记录在 SAGO 图表 **Circulation** 部分
- **脉搏记录是临床技能考核的必考项**

### ⚠️ 需带到实验课讨论的反思问题
1. 为什么一年级临床评估中我们评估**桡动脉**？
2. 为什么测脉搏时用 **2-3 指而不用拇指**？

## 7. AVPU / ACVPU（意识水平快速评估）

> 本单元不深入完整神经系统评估，重点是 AVPU/ACVPU 量表在生命体征图表中的记录方式。

### ACVPU 五个等级
| 字母 | 含义 | 表现 |
|---|---|---|
| **A** | Alert 清醒 | 完全清醒、有反应、能感知周围环境 |
| **C** | Confusion 意识模糊 | 新发或加重的意识混乱 |
| **V** | Verbal 对声音有反应 | 对语言刺激（呼名/说话）有反应 |
| **P** | Pain 对疼痛有反应 | 仅对疼痛刺激（如斜方肌捏、胸骨按压）有反应 |
| **U** | Unresponsive 无反应 | 对语言和疼痛刺激均无反应 |

### 为什么重要
帮助识别可能提示以下情况的神经系统变化：
卒中、头部损伤、低氧、低血糖、感染、药物作用、需要上报的病情恶化

> ⚠️ 从 A（清醒）突然变为 C（意识模糊）或 V（对声音反应），是**红色警示信号**，必须按 Between the Flags 标准立即上报。

### 文档记录
在 SAGO 图表神经系统部分用单个字母记录（A/C/V/P/U）。
**记录是临床技能考核的必考项**（原文档中有拼写为 "Cli8nical"，应为 Clinical 的笔误）。

## 8. 疼痛 (Pain) — "第五生命体征"

### 概念
> "疼痛是体验者所说的那样，只要他们说存在就存在。" — Pasero & McCaffery (2011)

疼痛是不愉快的感觉和情绪体验，与实际或潜在的组织损伤相关，受生物、心理、社会因素共同影响。

**未处理疼痛的后果：**
活动能力下降、营养摄入减少、睡眠受损、伤口愈合延迟、免疫抑制、情绪困扰（焦虑/抑郁）、慢性疼痛风险增加

### 疼痛分类
**按持续时间：**
- **急性疼痛 (Acute)** — 突发、短期、具保护性；数天至 3-4 周
- **持续性/慢性疼痛 (Persistent/Chronic)** — 持续 3 个月以上，可能无明确病因

**按病因：**
- **伤害性疼痛 (Nociceptive)** — 组织损伤引起（躯体性或内脏性）
  - Cutaneous（皮肤痛）：刺激皮肤神经末梢
  - Somatic（躯体痛）：非局限性，源于支持结构（韧带、肌腱、神经），如夹到手指
  - Visceral（内脏痛）：内脏器官引起，定位不清、传导较慢，评估困难
- **神经病理性疼痛 (Neuropathic)** — 周围或中枢神经系统异常处理引起
  - 周围性：糖尿病神经病变、腕管综合征
  - 中枢性：多发性硬化、脊髓损伤
- **躯体形式疼痛 (Somatoform)** — 心理性来源

**其他分类：**
- **牵涉痛 (Referred pain)** — 疼痛发生在一个器官但感觉在别处（如心脏病发作的疼痛可在左臂或下颌）
- 幻肢痛 (Phantom pain)
- 突破性疼痛 (Breakthrough pain)

### 影响疼痛体验的因素
年龄、文化、既往疼痛经历、情绪状态、疲劳、注意力/分散注意力、疼痛的意义、社会支持

### 疼痛评估
**第一步：直接询问患者**——疼痛不能被假设、轻视或评判。

评估内容：起病、部位、持续时间、特征、加重/缓解因素、对功能的影响、患者目标

**评估工具（本模块重点）：**
- **数字评分量表 (NRS)**：0=无痛，10=最痛
- **语言评分量表 (VRS)**：无痛/轻度/中度/重度/剧痛

（适用于能理解量表的青少年、成人、老年人）

### 文档记录
应包含：
- 疼痛评分（NRS 或 VRS）
- 部位与特征
- 已采取的干预措施
- 患者对治疗的反应
- 复评时间

记录位置：纸质图表 / eMR / SAGO 图表疼痛评分部分
**疼痛记录是临床技能考核的必考项**

## 9. 体温 (Body Temperature)

### 基础概念
体温 = 产热与散热之间的平衡，反映代谢活动、感染、炎症及体温调节功能。

**正常核心体温范围：** 36.0°C – 37.5°C（不同教材/指南略有差异）

**体温变化因素：**
- 个体差异
- 一天中的时间（早晨较低，午后较高）
- 测量部位（核心 vs 表面温度）

**常用测量部位：** 鼓膜 (tympanic)、颞部 (temporal)、腋下 (axilla)、口腔 (oral)、直肠 (rectal)

### 体温调节 (Thermoregulation)
人体通过内环境稳态维持体温恒定，涉及：
- **产热** — 代谢、肌肉活动
- **散热** — 皮肤、呼吸、汗液蒸发
- **神经调控** — 下丘脑

这种平衡对酶功能、细胞活动及整体生理稳定至关重要。

> 思考题：环境如何影响体温测量结果？为什么术后患者常会发生寒颤？

### 术语
| 术语 | 含义 |
|---|---|
| Pyrexia | 体温高于正常上限 37°C |
| Febrile | 体温通常超过 39.5°C |
| Hyperthermia | 异常高体温 |
| Hypothermia | 体温低于 35.4°C |
| Thermoregulation | 体温调节机制 |

## 10. 文档记录 (Documentation)

### 为什么文档记录重要
- **基线指标** — 建立患者正常生理状态的起点，偏离基线可提示病情变化
- **趋势监测** — 定期记录可发现体温上升、血压下降、呼吸加快等模式
- **临床决策** — 支持及时干预、上报与治疗计划
- **沟通** — 生命体征是医疗团队的"共同语言"
- **法律与伦理责任** — 记录是护理提供的法律证明

### 高质量文档的原则
| 原则 | 说明 |
|---|---|
| Clear 清晰 | 易读易懂 |
| Legible 可辨认 | 手写或电子记录必须无歧义 |
| Concise 简洁 | 只包含相关信息 |
| Contemporaneous 即时性 | 测量后立即记录 |
| Progressive 连续性 | 体现随时间的变化 |
| Accurate 准确 | 数值、单位、解读均正确 |
| Complete 完整 | 包括评估、已采取措施、结果、复评计划 |
| Sequential 按时间顺序 | 支持趋势识别 |
| Free from gaps/overwriting 无空白/涂改 | 每条记录完整、不可篡改 |

**记录形式：** 纸质 / 电子 (eMR) / 混合，取决于医疗机构
**记录载体举例：** 护理计划、观察图表、交班记录、转诊信、病理申请单、手术记录、出院总结

### 记录前的解读（不是简单地抄数字！）
记录前应思考：
- 这个数值对这个患者是否正常？
- 是否符合其基线？
- 是否有趋势正在发展？
- 是否需要上报（如 Between the Flags 标准）？
- 是否需要提前复评？
- 是否需要与 RN 或医疗团队沟通？

### 记录位置
- **SAGO 图表**（NSW 与 QLD 版本不同，模块中都有介绍）
- 电子病历 (eMR)
- 临床病历记录（如上报、干预、患者反应等相关内容）

各生命体征在图表上都有指定区域：体温、脉搏/心率、呼吸频率、血压、血氧饱和度、疼痛评分、AVPU

### 文档缺失/不良的后果
误诊、延误治疗、用药错误、未能及时上报、可预防的病情恶化未被发现

### SAGO 图表 (Standard Adult General Observation Chart)
NSW Health 用于记录生命体征并识别早期病情恶化的工具，使用颜色编码区域（黄区/红区），支撑 Between the Flags 安全系统。

**准确记录的原则：**
- **及时 (Timely)** — 尽快记录以保证准确性
- **可辨认 (Legible)**
- **按顺序 (Sequential)** — 支持趋势识别
- **与患者表现一致 (Consistent)** — 数值应与临床所见相符，不符则需复查
- **无空白或涂改**
- **异常值需核实**

**法律要求：**
- 准确及时
- 清晰可辨
- 内容全面（时间、日期、患者标识、临床背景）
- 遵守机构政策与规范
- 安全、永久保存

**与国家标准的关联：** 符合 NSQHS 标准中的
**Standard 1（临床治理 Clinical Governance）** 和 **Standard 6（安全沟通 Communicating for Safety）**

## 11. 患者安全 (Patient Safety)

### 核心理念
> "First, do no harm"（首先，不伤害）— 医疗服务最根本的原则

患者安全的三个关键要素：
1. **预防错误**
2. **从错误中学习**
3. **培养涉及医护人员、机构与患者的安全文化**

WHO 将患者安全定义为：随着医疗系统日益复杂而发展出的学科，旨在**预防和减轻**患者在医疗过程中可能遭遇的风险、错误与伤害。

**实现患者安全的行动包括：**
遵守政策、提出关切、批判性思维、自我反思、事故上报（incident reporting）

**澳大利亚层面：** 建立了 **NSQHS 标准**（国家安全与质量医疗服务标准），由澳大利亚医疗安全与质量委员会 (ACSQHC) 推动。

### 医疗错误的成因 — Swiss Cheese Model（瑞士芝士模型）
由 James Reason 于 1990 年代提出的风险管理理论：
- 医疗系统的多层防御（如瑞士芝士的切片）**每一层都有"孔洞"**（漏洞）
- 当这些孔洞**排列对齐**时，错误会"穿透"所有防御层，最终伤害到患者
- 强调错误通常是**多重系统弱点叠加**的结果，而非单一失误

该模型帮助护士理解：
- 系统因素如何导致伤害
- 为何需要多重安全保障措施
- 沟通、工作量、环境、人为因素如何影响安全

### 从错误中学习 / 上报错误与临界差错 (Near Misses)
澳大利亚医疗系统整体表现良好，但仍存在安全挑战。

**事故上报的作用：**
- 支持系统改进
- 为安全宣传活动提供信息
- 预防未来伤害
- 强化开放与问责的文化

> 作为学生，在临床实习中完成事故报告时会得到指导和支持。
